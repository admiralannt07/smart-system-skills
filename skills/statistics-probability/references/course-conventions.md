# Course conventions

- Teach in the user's requested language. Preserve Indonesian lecture terminology in citations: populasi/population, sampel/sample, rata-rata/mean, simpangan baku/standard deviation, ruang sampel/sample space, kejadian/event.
- Deck 1 slide 7: N denotes population size, n sample size. Deck 1 slide 60: mu denotes population mean, x-bar sample mean. These user-confirmed meanings do not validate every printed formula.
- Deck 2 slide 11: Omega denotes the full sample space. An event is a subset, including the empty or full set.
- Deck 2 slide 14: indexed omega labels events locally. Preserve those labels and explain their set role. Deck 2 slide 19 uses N for configuration count. Resolve symbol scope from definitions and formula role.
- Operational sample mean: sum(x_i)/n; population mean: sum(x_i)/N. Sample variance: sum((x_i-xbar)^2)/(n-1), n>1; population variance: sum((x_i-mu)^2)/N. Do not copy the conflicting slide 7/60 expressions as verified mathematics.
- Retain precision until final presentation. Report units; variance has squared units, SD original units. State any requested rounding. No invented grading rubric.
- Grouped mean uses class midpoints and is approximate; grouped median/mode require declared true boundaries, widths, and frequency definitions. Quantiles require a named algorithm. Do not claim a lecturer-specific convention where none is established.
- Pearson second skewness is 3(mean-median)/SD, undefined for zero SD. Do not equate it with moment skewness. Kurtosis must specify raw or excess convention; tail behavior cannot be reduced to peak height alone.

Independent mathematics: [NIST location](https://www.itl.nist.gov/div898/handbook/eda/section3/eda351.htm), [NIST scale](https://www.itl.nist.gov/div898/handbook/eda/section3/eda356.htm), [NIST skewness and kurtosis](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35b.htm), [OpenStax counting](https://openstax.org/books/college-algebra-2e/pages/9-5-counting-principles). These establish mathematics, not instructor intent or matching symbol choices.
