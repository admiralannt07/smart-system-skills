# Available concept routes

These are implemented bounded skills, not a complete syllabus. Read only matching routes and required prerequisites. Exact contracts/coverage: [manifest.json](manifest.json).

| Skill | Use for |
| --- | --- |
| [data-foundations](../subskills/data-foundations/SKILL.md) | Classify observations, population/sample scope, measurement scales, data origins, and quality before choosing statistical methods. |
| [data-presentation](../subskills/data-presentation/SKILL.md) | Choose and explain frequency tables, bar/pie/line charts, histograms, boxplots, and scatterplots from variable roles and the analytical question. |
| [central-tendency](../subskills/central-tendency/SKILL.md) | Compute and interpret mean, weighted/grouped mean, median and mode; compare representative values and sensitivity to unusual observations. |
| [data-dispersion](../subskills/data-dispersion/SKILL.md) | Compute and interpret range, variance, standard deviation, quartiles, IQR, z-scores, outlier flags, skewness and kurtosis with explicit scope and conventions. |
| [sample-space-events](../subskills/sample-space-events/SKILL.md) | Model finite outcomes, sample spaces, events, unions, intersections and complements, including QA configurations and locally scoped notation. |
| [counting-principles](../subskills/counting-principles/SKILL.md) | Count staged configurations using multiplication, disjoint cases, and explicit forbidden-case constraints; verify small counts by enumeration. |
| [permutations](../subskills/permutations/SKILL.md) | Count ordered selections, distinct-object arrangements, repeated-object full arrangements and repetition-allowed strings, including dependency constraints. |
| [combinations](../subskills/combinations/SKILL.md) | Count unordered selections and teams using binomial coefficients, distinguish permutations, and enforce subset constraints without double counting. |

Only the root coordinates ordered composition. Unknown topics remain not imported; directory presence does not establish student mastery.
